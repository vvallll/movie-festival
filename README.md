# ✦ Film Festival ⋆｡°✩

A website for a fictional independent film festival, created entirely as a personal HTML practice project.

The festival itself is **imaginary**, but its concept is inspired by my own taste in cinema — particularly classic cinema, auteur filmmaking, and stories that leave you with something to think about long after the credits.

### ⊹ About the project

The website brings together everything a festival visitor might need:

→ festival information and programme
→ featured films and screenings
→ a detailed schedule
→ ticket information and booking
→ information about the festival
→ contact and newsletter forms

The programme is built around a deliberately curated selection of films that reflects the kind of cinema I personally enjoy: atmospheric, character-driven, visually distinctive, and occasionally a little strange.

### ୨୧ What this project was about

This project was built as a **hands-on HTML practice**, with a focus on creating a complete multi-page website rather than isolated exercises.

It allowed me to practise:

`semantic HTML` · `navigation` · `links` · `images` · `tables` · `forms` · `accessibility` · `page structure`

The goal was simple: take everything learned in the fundamentals and turn it into something that actually feels like a real website.

`learn → build → break → fix → repeat` ⊹
